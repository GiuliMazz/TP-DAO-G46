# Archivo histórico del proyecto

Material conservado por trazabilidad, fuera del código vigente. Git conserva DOT y PNG originales, este índice y el documento inicial de continuidad. ZIP, muestras, cachés y duplicados quedan excluidos; pueden seguir existiendo en el equipo original, pero no son necesarios para un clon.

| Carpeta | Contenido |
|---|---|
| paquetes/ — sólo local | Los cuatro ZIP originales de muestras y etapa 1 |
| openlibrary/ — sólo local | Extractores anteriores, muestras de 30/1.000 obras, segunda versión y cachés de búsqueda |
| [diagramas/](./diagramas/) | DOT y PNG originales versionados para consultar el modelo histórico |
| [documentos_iniciales/](./documentos_iniciales/) | Continuidad histórica versionada; presentación compacta y contrato duplicado sólo locales |

## Dónde seguir trabajando

- Código de aplicación: [biblioteca/](../biblioteca/) y [tests/](../tests/).
- Diseño y plan actual: [docs/](../docs/) y [PLAN_DESARROLLO.md](../PLAN_DESARROLLO.md).
- Consigna, presentación original del grupo y Semana 1: [docs/referencias/](../docs/referencias/).
- Pipeline vigente y contrato compartido: [herramientas/openlibrary/](../herramientas/openlibrary/).
- Insumos canónicos y prevalidación de referencia: [datos/openlibrary/](../datos/openlibrary/).

Las copias históricas del catálogo exploratorio, respuestas detalladas y contrato se comprobaron idénticas a sus versiones vigentes mediante SHA-256 antes de moverlas. Se conservan para mantener íntegros los paquetes y muestras originales.

Las instrucciones históricas pueden mencionar nombres o distribuciones de carpetas anteriores. Usar el README principal y el plan vigente para ejecutar y continuar. Los diagramas actuales del diseño están en documentos UML de docs; estos DOT/PNG originales no se actualizarán automáticamente.
